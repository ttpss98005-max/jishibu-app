# 記事簿 Android App(含桌面月曆小工具)

第一版功能:今天、清單(勾選/新增事項與子事項)、行事曆、習慣打卡、設定,加上桌面月曆小工具。
資料和網頁版記事簿是同一份(雲端同步),網頁版照常可用。
第一版還沒有:編輯/刪除事項、新增習慣、記帳、筆記、搜尋、推播提醒。

## 怎麼拿到 APK(不用裝 Android Studio)
1. 到 GitHub 建一個新的儲存庫,名字隨意(例如 `jishibu-widget`),選 **Public**(裡面沒有任何你的資料)。
2. 把這個資料夾**裡面所有東西**上傳到儲存庫根目錄(Add file → Upload files)。
   - 一定要包含隱藏資料夾 `.github`(Mac 按 Cmd+Shift+. 可顯示隱藏檔)。
   - 如果 `.github` 傳不上去:在 GitHub 按 Add file → Create new file,檔名輸入 `.github/workflows/build-apk.yml`,把本資料夾裡同名檔案的內容貼進去存檔。
3. 上傳完會自動開始編譯。到儲存庫的 **Actions** 分頁,等出現綠色勾勾(約 3–5 分鐘)。
4. 到儲存庫右側的 **Releases**,點最新的版本,下載 `jishibu-widget.apk`(就是記事簿 App)。
5. 在手機上開啟這個檔案安裝(第一次要允許「安裝未知來源 App」)。

## 怎麼連結資料
1. 先把新版記事簿網頁部署上去(含「設定 → 桌面小工具」按鈕),手機上重新開啟記事簿。
2. 記事簿 → 設定 → 桌面小工具 → 按「連結桌面小工具」,會跳到小工具 App 自動連結。
   - 沒有跳過去的話:按「複製連結碼」,打開小工具 App,貼上後按「連結」。
3. 在 App 設定頁按「把月曆小工具放到桌面」(想要桌面月曆的話)。

## 之後更新
改了程式再上傳到同一個儲存庫,會自動產生新的 Release,下載新的 APK 直接覆蓋安裝即可(簽章固定,不用先解除安裝)。

## 常見狀況
- 顯示「更新失敗:HTTP 401/403」:把這行字告訴開發者。
- 勾選或新增會先立刻顯示在手機上,再自動同步到雲端;沒網路時會先存著,有網路再補上。
- 小工具會每 30 分鐘左右自動更新;點右上角 ↻ 可以立刻更新;點月份標題回到本月。
- 小工具拉高(拉大)後,每一格才會顯示事項名稱;小的時候只顯示小圓點。
